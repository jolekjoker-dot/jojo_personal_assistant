# 每日总结技能

## 目标
基于今天的对话历史和项目文件，生成一份简洁的每日工作总结。

## 执行流程

### 第一步：收集上下文
1. 先用 `list_files` 查看项目根目录和 src/jojo/ 子目录，找出今天修改过的文件
2. 用 `read_file` 逐个读取今天修改过的关键文件：
   - 优先读 README.md（项目概况）
   - 读 src/jojo/ 下今天修改过的核心模块（config、agent、memory、orchestrator 等）
   - 读 data/jojo.log（今天的操作记录）
3. 不需要读测试文件和文档，只读业务代码

### 第二步：基于已知信息总结
根据文件内容和当前对话历史，按以下分类组织：
- **已完成**：完成的任务、写好的代码
- **进行中**：正在进行的模块
- **决策记录**：架构选择、技术选型
- **今日学习**：新知识、新发现

### 第三步：格式化输出

```
## 每日总结 — {日期}

### 已完成
- [已完成事项]

### 进行中
- [进行中事项]

### 决策记录
- [关键决策]

### 今日学习
- [新学到的东西]
```

## 规则
- 要具体 — 提到文件名、模块名、修改内容
- 保持简洁 — 每条一行
- 关注结果，而不是过程
